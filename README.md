One line in the voice of a hardware wallet refusing to sign at 3 AM: three years guarding $12,400 without blinking, and it will not sign until the sun and its owner's judgment come back.

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (and prints it to stdout).
